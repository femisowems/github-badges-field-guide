# GitHub Badges — A Collector's Field Guide

A fun side project: every GitHub profile badge in one place, with the actual badge artwork, how each one is earned, and the tier thresholds.

**Open `index.html` in a browser to browse the guide** — it's a single self-contained file with all the artwork embedded. Or enable GitHub Pages on this repo (Settings → Pages → deploy from `main`) to view it online.

## What's inside

- **8 earnable achievements** — Quickdraw, YOLO, Pull Shark, Pair Extraordinaire, Galaxy Brain, Starstruck, Public Sponsor, Finishing Touch
- **2 retired** — Arctic Code Vault Contributor, Mars 2020 Contributor
- **2 unreleased experiments** — Heart On Your Sleeve, Open Sourcerer
- **3 staff-only** — the Proxima trio (Pioneer, Staffshipper, Staffuser)
- **6 Highlights** — Pro, Developer Program Member, Security Bug Bounty Hunter, GitHub Campus Expert, Security Advisory Credit, GitHub Star

Tiers run Default → Bronze (x2) → Silver (x3) → Gold (x4); a profile displays the highest tier held.

GitHub doesn't publish an official list of achievements, so the thresholds here are community-verified (checked Nov 19, 2026) against GitHub's Docs profile reference and the community catalogs:
